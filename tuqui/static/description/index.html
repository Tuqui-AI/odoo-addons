What this module does

The native Tuqui integration

tuqui is the full companion module: it registers Tuqui inside your Odoo, adds a one-click activation block in Settings, and keeps an access log of every AI query — all native, no external dashboards needed.

⚙️

Native Settings UI

A Tuqui block appears directly under Settings → Integrations. One click to activate — no tokens to copy by hand.
📋

Built-in access log

Every AI query is logged. Audit who asked what and when, right from inside your Odoo — no external tool needed.

Security

Secure by design

Read-only

Tuqui never writes or changes any data in your Odoo. It only reads.

OAuth 2.0 with PKCE

Industry-standard authentication. No shared passwords or exposed tokens.

Auditable access log

Every query is logged. Audit what was queried and when, right from your Odoo.

Data stays on your server

Your Odoo data is never stored on Tuqui's servers. It's queried live and returned only to you.
