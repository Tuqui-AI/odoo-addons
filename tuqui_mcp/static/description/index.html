¿Qué es Tuqui?

Tuqui es un servidor MCP que expone tu Odoo como un conjunto de herramientas que cualquier asistente de IA puede usar. Preguntale a Claude o ChatGPT sobre tus ventas, stock, clientes o facturas — y va a responder con datos reales de tu sistema.

Este módulo registra los parámetros de conexión necesarios para que tu Odoo pueda comunicarse con Tuqui. Es data-only: no instala código Python ni modifica ningún modelo existente. Compatible con Odoo Online, Odoo.sh y On Premise.

¿Cómo funciona?

1️⃣

Instalá el módulo

Instalalo desde Odoo Apps. Registra automáticamente los parámetros de Tuqui en tu sistema.

2️⃣

Conectá tu espacio

En tuqui.com creás tu workspace y autorizás el acceso a tu instancia de Odoo.

3️⃣

Preguntá lo que necesitás

Desde Claude, ChatGPT o cualquier cliente MCP, hacé preguntas sobre tu negocio en lenguaje natural.

Preguntá lo que necesitás

💬  «¿Cuáles son las ventas del último mes por vendedor?»
💬  «¿Qué productos tienen stock bajo mínimo?»
💬  «Mostrame las facturas vencidas de los últimos 30 días.»
💬  «¿Cuál es el cliente con mayor facturación este año?»

Seguro por diseño

Solo lectura

Tuqui no escribe ni modifica ningún dato en tu Odoo. Solo consulta.

OAuth 2.0

La autenticación usa el estándar OAuth 2.0 con PKCE. Sin contraseñas compartidas.

Datos en tu servidor

Tus datos de Odoo nunca se almacenan en los servidores de Tuqui.

Protocolo MCP estándar

Compatible con cualquier cliente que implemente el estándar MCP de Anthropic.
