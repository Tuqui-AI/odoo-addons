In the panel

Contextual chat Voice input Proposed changes Chatter drafts

No copy-paste

It sees the screen you are on

You never have to explain which record you mean. The panel receives the context of the active view and updates it as you move around Odoo.

On a form

The open record and the values currently on screen — including edits you have not saved yet. Ask “is this quote consistent?” and it answers about that quote.

On a list

The active filters, the result count and whatever you selected. Ask “what do these 40 overdue invoices have in common?” without exporting anything.

On a kanban

The same context from a kanban view, so a pipeline or a task board can be read and summarised in place.

Propose, then apply

Nothing is saved without you

The assistant does not write to your database. It fills the form in front of you and stops there — the Save and Discard buttons are still yours.

01

You ask

“Complete the missing fields”, “write the follow-up note”, “fix the delivery address”. In your own words, by keyboard or voice.

02

It proposes

The change lands on the open form with the reasoning behind it. The fields light up as unsaved changes, exactly as if you had typed them.

03

You decide

Save to keep it, Discard to drop it. Same buttons, same permissions, same audit trail as any other edit in Odoo.

Chatter drafts, never sent alone

Ask for a reply to a customer and the native chatter composer opens pre-filled. The assistant never posts a message on its own.

It can take you there

When the answer lives in another view, the assistant opens it for you in Odoo — the right model, the right filter, already applied.

How it works

Set it up in 3 steps

No tokens to copy, no second login. The connection is inherited from the companion module.

01

Connect Tuqui

Install the free Tuqui Companion module and activate it from Settings → Integrations, in one click.

02

Install this module

Nothing else to configure: the assistant reads the workspace and the connection already activated by the companion.

03

Open the panel

A Tuqui button appears in the top bar of the backend. Click it and the assistant opens next to your view, already signed in as you.

Security

Secure by design

No second login

Sign-on uses a single-use token bound to your own Odoo user and valid for seconds. Nobody can open the assistant as somebody else.

Your permissions apply

The assistant works with your access rights. It cannot read or change anything you could not read or change yourself.

No silent writes

Every proposed change waits on the form for you to save or discard it. Nothing reaches the database on its own.

Auditable access

The companion logs every query Tuqui makes to your Odoo, so you can audit what was read and when.
